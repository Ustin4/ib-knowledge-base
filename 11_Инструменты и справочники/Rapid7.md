# Rapid7

Rapid7
Как и другие сервисы, такие как Exploit DB и NVD, Rapid7 — это база данных для исследования уязвимостей. Единственное отличие заключается в том, что эта база данных также является базой данных эксплойтов.  Используя этот сервис, вы можете фильтровать данные по типу уязвимости (например, по приложению и операционной системе).

Searchsploit
Searchsploit — это инструмент, доступный в популярных дистрибутивах для пентестинга, таких как Kali Linux . Он также доступен в TryHackMe AttackBox. Этот инструмент представляет собой офлайн-копию Exploit-DB, содержащую копии эксплойтов для вашей системы.
