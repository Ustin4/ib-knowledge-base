# NodeJsScan

NodeJsScan
(откроется в новой вкладке)
NodeJsScan — это статический сканер кода безопасности для приложений Node.js. Он включает проверку на различные уязвимости безопасности, в том числе на загрязнение прототипов. Интеграция NodeJsScan в ваш рабочий процесс разработки может помочь автоматически выявлять потенциальные проблемы безопасности в вашем коде. 
Прототип сканера загрязнения
(откроется в новой вкладке)
 Это инструмент, предназначенный для сканирования кода JavaScript на наличие уязвимостей, связанных с загрязнением прототипов. Он может использоваться для анализа кодовых баз на предмет шаблонов, подверженных загрязнению, помогая разработчикам выявлять и устранять потенциальные проблемы безопасности в своих приложениях.
PPFuzz
(откроется в новой вкладке)
 Это еще один фаззер, предназначенный для автоматизации процесса обнаружения уязвимостей, связанных с загрязнением прототипов, в веб-приложениях. Путем фаззинга входных векторов, которые могут взаимодействовать со свойствами объектов, PPFuzzон может помочь выявить точки в приложении, подверженные загрязнению прототипов. 
Обнаружение на стороне клиента с помощью BlackFan
(откроется в новой вкладке)
Данная работа посвящена выявлению уязвимостей, связанных с загрязнением прототипов, в клиентском JavaScript. Она включает примеры того, как загрязнение прототипов может быть использовано в браузерах для выполнения определенных действий.XSSатаки и другие вредоносные действия. Это ценный ресурс для понимания влияния загрязнения прототипами на сторону клиента.
