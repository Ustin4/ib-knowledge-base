# Повышение привилегий в Linux машинах

Имя хостов
The hostname Команда вернет имя хоста целевой машины. 

/proc/версия
Файловая система proc (procfs) предоставляет информацию о процессах целевой системы. Вы найдете Proc на многих различных вкусах Linux
Глядя на /proc/version может предоставить вам информацию о версии ядра и дополнительные данные, например, является ли компилятор (например, GCC) устанавливается.
/etc/issue 
Системы также могут быть идентифицированы, взглянув на /etc/issue Файл. Этот файл обычно содержит некоторую информацию об операционной системе, но может быть легко настроен или изменен. 


The ps Командование Это эффективный способ увидеть запущенные процессы в системе Linux. 
О результатах этого ps покажет следующее:
PID: ID процесса (уникальный для процесса)
TTY: Тип терминала, используемый пользователем
Время: количество времени процессора, используемого процессом (это НЕ время, когда этот процесс запущен)
CMD: команда или исполняемый запуск (не отображается ни один параметр командной строки)
Команда «PS» предоставляет несколько полезных опций.
ps -A: Просмотр всех процессов запуска
ps axjf: Просмотр дерева процесса (см. образование дерева до ps axjf работает ниже)

Env
The env Команда будет отображать переменные окружающей среды.


Читать /etc/passwd 
Файл Это может быть простой способ узнать пользователей в системе 
Для того чтоб меньше лишней информации то можно сделать cat /etc/passwd | cut -d ":" -f 1
Тогда будут только имена пользователей для перебора грубой силой 

Так как там могут быть пользователи которые нам особо и не нужны которые грубо говор не дома так как для пользователей системы есть каталог папка home 
и можно по ней отфильтровать пользователь 
к пример: cat /etc/passwd | grep home

Хеш паролей 
/etc/shadow
netstat
После первоначального проверить на наличие интерфейсов и сетевых маршрутов, стоит посмотреть в существующие коммуникации. The netstat Команда может быть использована с несколькими различными вариантами сбора информации о существующих Связи.

netstat -a: шоу все порты прослушивания и установленные соединения.
netstat -at или netstat -au также может быть использован для перечисления протоколов TCP или UDP соответственно.
netstat -l: список порты в режиме «прослушивания». Эти порты открыты и готовы к Принимать входящие связи. Это можно использовать с опцией «t» для перечисления только порты, которые слушают, используя протокол TCP (ниже)
netstat -s: список статистики использования сети по протоколам (ниже) Также может быть использован с -t или -u Варианты для ограничения Вывод в конкретный протокол. 
netstat -tp: список соединений с именем службы и PID Информация.

Пример команд для поиска файлов 
Найти файлы:
find . -name flag1.txt: найти файл под названием "flag1.txt" в Текущий каталог
find /home -name flag1.txt: найти имена файлов “flag1.txt” in в /домашнем каталоге
find / -type d -name config: найти каталог под названием конфигурация под "/"
find / -type f -perm 0777: найти файлы с разрешениями 777 (файлы, читаемые, записываемые и исполняемые всеми пользователями)
find / -perm a=x: найти исполняемые файлы
find /home -user frank: найти все файлы для пользователя «frank» под «/дом»
find / -mtime 10: найти файлы, которые были изменены в последние 10 Дни
find / -atime 10: найти файлы, которые были доступны в последние 10 день
find / -cmin -60: найти файлы, измененные в течение последнего часа (60) минут)
find / -amin -60: найти доступ к файлам в течение последнего часа (60) минут)
find / -size 50M: найти файлы с размером 50 МБ

find / -perm -o x -type d 2>/dev/null: Найдите исполняемые в мире папки

Найдите инструменты разработки и поддерживаемые языки:
find / -name perl*
find / -name python*
find / -name gcc*

Найдите конкретные разрешения файлов:
find / -perm -u=s -type f 2>/dev/null: Найти файлы с помощью SUID бит, который позволяет нам запускать файл с более высоким уровнем привилегий чем у нынешнего пользователя.
