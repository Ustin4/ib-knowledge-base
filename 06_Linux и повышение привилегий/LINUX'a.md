# LINUX'a


Операторы:
    & - запуск команд в фоновом режиме в терминале
    && - логическое "И"
    > - оператор перенаправления (вывод команд в другом месте + перезаписывает инфу в файле)
    >> - тоже, что и ">", но добавляет результат, а не заменяет его

Директории:
    /etc - хранит системные файлы (shadow, passwd и т.д.)
    /var - хранит различные данные (хуйню короч типо логов)

Процессы:
    crontab - процесс, предназначенный для выполнения задач cron

Команды:
    scp - копирование с ssh (src -> dst)
    ps aux - просмотр активных процессов
    top - статистика процессов
    systemctl [option] [service] - взаимодействие с демоном systemd (пример systemctl enable apache2 - для запуска процесса при загрузке системы)
    fg - возврат фонового процесса (отправленный при помощи & или Ctrl+Z) на передний план.
    SIGTERM — завершает процесс, но позволяет ему предварительно выполнить некоторые задачи по очистке
    SIGKILL — завершение процесса — не выполняет никаких действий по очистке после завершения
    SIGSTOP — остановка/приостановка процесса
    crontab -e - редактирование crontab
    ss - замена netstat (инфа о сети)
