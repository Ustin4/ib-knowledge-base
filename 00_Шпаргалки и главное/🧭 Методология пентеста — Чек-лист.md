# 🧭 Методология пентеста — Чек-лист

## 1. Разведка (Reconnaissance)
- [ ] Пассивный сбор: `whois`, `dig`, `crt.sh`, `waybackurls`, Google Dorks
- [ ] Поиск поддоменов (`subfinder`, `amass`, `ffuf` VHost)
- [ ] Проверка метаданных документов/изображений (`exiftool`)

## 2. Сканирование и перечисление (Scanning & Enumeration)
- [ ] Полное сканирование TCP-портов (`nmap -p-`)
- [ ] Детальное сканирование открытых портов (`nmap -sC -sV`)
- [ ] Перечисление веб-директорий и файлов (`gobuster`, `ffuf`)
- [ ] Проверка стандартных сервисов: SMB (`445`), FTP (`21`), SSH (`22`), SNMP (`161`), RDP (`3389`)

## 3. Анализ уязвимостей и эксплуатация (Exploitation)
- [ ] Веб: проверка на SQLi, XSS, SSTI, LFI/RFI, SSRF, IDOR, Command Injection
- [ ] Проверка HTTP-заголовков и десинхронизации (Request Smuggling)
- [ ] Поиск публичных эксплойтов (`searchsploit`, Metasploit, GitHub)
- [ ] Получение первичного доступа (Reverse Shell + стабилизация TTY)

## 4. Повышение привилегий (Privilege Escalation)
- [ ] **Linux**: `sudo -l`, SUID, Cron, PATH Hijacking, NFS `no_root_squash`, `linpeas.sh`
- [ ] **Windows**: `whoami /priv`, Unquoted Service Paths, Scheduled Tasks, поиск паролей в реестре/конфигах, `winPEAS`

## 5. Пост-эксплуатация и фиксация результатов
- [ ] Сбор доказательств (флаги, скриншоты, команды)
- [ ] Очистка временных файлов (при необходимости в лаборатории)
