# Перечисление поддоменов

Позволяет через этот сайт проверить все сертификаты который были выдано для этого домена и его поддоменов  
https://crt.sh/

Можно использовать OSINT и гугл Доркин
site:*.domain.com -site:www.domain.com 
Будет отображать только результаты, ведущие к доменному имени domain.com, но исключать любые ссылки на www.domain.com

DNS Bruteforce 
DNS Bruteforce можем использовать утилиту dnsrecon

Базовый поиск поддоменов для example.com
dnsrecon -d example.com

Попытка зонного трансфера
dnsrecon -d example.com -t axfr

Использовать словарь для перебора поддоменов
dnsrecon -d example.com -D /usr/share/wordlists/subdomains.txt -t brt

Sublist3r
Sublist3r — это специализированный инструмент для автоматического поиска поддоменов веб-сайтов. Если DNSRecon — это "детектив" широкого профиля, то Sublist3r — это "охотник за поддоменами", который фокусируется на одной задаче и делает её очень эффективно.

Базовый запуск:

python sublist3r.py -d example.com
Результат: список всех найденных поддоменов в терминале.

С сохранением в файл:
python sublist3r.py -d example.com -o subdomains.txt

С дополнительной проверкой через словарь:
python sublist3r.py -d example.com -b -p 80,443
-b = брутфорс по словарю
-p = проверять эти порты у найденных поддоменов

Virtual Hosts
Запись DNS может храниться на частном DNS- сервере или записываться на компьютерах разработчиков в файл /etc/hosts (или c:\windows\system32\drivers\etc\hosts для пользователей Windows), который сопоставляет доменные имена с IP-адресами. 

Поскольку веб-серверы могут размещать несколько веб-сайтов на одном сервере, при запросе веб-сайта от клиента сервер знает, какой веб-сайт хочет получить клиент, из заголовка Host. Мы можем использовать этот заголовок Host, внося в него изменения и отслеживая ответ, чтобы увидеть, обнаружили ли мы новый веб-сайт.

Пример команды через ffuf:
user@machine$ ffuf -w /usr/share/wordlists/SecLists/Discovery/DNS/namelist.txt -H "Host: FUZZ.acmeitsupport.thm" -u http://10.65.145.246

Можно отфильтровать чтоб получить более понятную информацию:
user@machine$ ffuf -w /usr/share/wordlists/SecLists/Discovery/DNS/namelist.txt -H "Host: FUZZ.acmeitsupport.thm" -u http://10.65.145.246 -fs {size}
Нужно заменив {size} на наиболее часто встречающееся значение размера из предыдущего результата
