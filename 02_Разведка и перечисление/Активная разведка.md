# Активная разведка

tracerouteдля
 отображения пути к целевому объекту
 ping
проверки ответа целевой системы на ICMP Echo и 
telnet
проверки того, какие порты открыты и доступны, пытаясь подключиться к ним


Command                                                              Example
ping                                                                         ping -c 10 10.67.178.49 on Linux or                                                                                       macOS
ping                                                                        ping -n 10 10.67.178.49 on MS                                                                                                Windows
traceroute
                                                                                traceroute 10.67.178.49 on Linux or                                                                                      macOS
tracert                                                                    tracert 10.67.178.49 on MS Windows
telnet                                                                      telnet 10.67.178.49 PORT_NUMBER
netcat as client                                                      nc 10.67.178.49 PORT_NUMBER
netcat as server                                                     nc -lvnp PORT_NUMBER
