# В php можно добавить знак тильда для получение временных файлов

PHP Цепь гаджетов (PHPGGC)
PHPGGC — это прежде всего инструмент для генерации цепочек гаджетов, используемых в PHP атаки с инъекцией объектов, специально разработанные для эксплуатации уязвимостей, связанных с PHP сериализация объектов и десериализация.

Как использовать 
Это позволяет выбрать подходящую цепочку гаджетов для вашего сценария эксплуатации, как показано ниже:-l 
php phpggc -l
