# Phishing Analysis Tools


Извлечь максимальное количество артефактов (IoC) из заголовка, тела и вложений письма.

1. АНАЛИЗ ЗАГОЛОВКА (Header Analysis)
Что ищем: IP отправителя, путь прохождения письма (MTA), Reply-To, подлинность.
Инструмент
Назначение
Особенность
Google Admin Toolbox (Messageheader)
Декодирование и визуализация SMTP-заголовков
Помогает найти проблемы маршрутизации и задержки
Message Header Analyzer (mha.azurewebsites.net)
Анализ заголовков
Альтернативный парсер
mailheader.org
Анализ заголовков
Простой интерфейс
IPinfo.io
Геолокация, ASN, whois по IP
Определение источника отправителя
PhishTool
Комплексный анализ
Автоматически парсит заголовки + SMTP-ретрансляторы

2. АНАЛИЗ ТЕЛА ПИСЬМА (Body & URLs)
Что ищем: Ссылки (в т.ч. сокращенные), домены, контент страницы.
🔗 Извлечение URL:
Вручную: Копировать расположение ссылки (Copy Link Location).
URL Extractor: Вставить сырой заголовок/письмо -> получить список всех URL.
CyberChef: Рецепт «Extract URLs».
🌐 Анализ репутации URL/Домена:
urlscan.io — Сканирует сайт как обычный пользователь. Показывает скриншот, DOM, запросы JS/CSS, файлы cookie, связанные IP. Автоматически определяет фишинг на 400+ брендов.
Альтернативы: URL2PNG, Wannabrowser (для скриншотов).

3. АНАЛИЗ ВЛОЖЕНИЙ (Attachments)
Что ищем: Хеш, репутация файла, поведение (в песочнице).
📦 Получение хеша:
bash
sha256sum [имя_файла]
🛡️ Проверка репутации по хешу:
Cisco Talos File Reputation — проверка по хешу.
VirusTotal — поиск по хешу, детекты антивирусов.
Reversing Labs — сервис репутации файлов.
🧪 Песочницы (анализ поведения):
Any.Run — интерактивный анализ (кликаешь по ОС в браузере).
Hybrid Analysis — гибридный анализ + сообщество.
Joe Sandbox — глубокий анализ: ИИ-детект фишинга, Yara/Sigma, MITRE ATT&CK.

4. «КОМБАЙН» ДЛЯ АНАЛИТИКА (PhishTool)
PhishTool — бесплатная версия для сообщества.
Что делает: Скармливаешь письмо (EML/MSG) → на выходе получаешь готовую карточку инцидента.
Фишки:
Подтягивает все данные заголовка (IP, SPF, обратный DNS).
Интегрируется с VirusTotal (нужен API-ключ).
Извлекает строки (Strings) из вложений.
Позволяет «приговорить» файл (Resolve) — пометить как вредоносный и закрыть таск.

📋 Блокнот аналитика: Что должно быть в итоговом отчете
От кого: Email + IP отправителя (и обратный поиск IP).
Кому: Получатель (To, CC, BCC).
Когда: Timestamp письма.
Техничка: SMTP-ретрансляторы (X-Originating-IP, Return-Path).
Артефакты:
Список URL (полные, декодированные).
Имя вложения + Хеш (SHA256).
Вердикт: Репутация домена/файла (Talos/VT), поведение в песочнице.
Совет: Ни один инструмент не дает 100% картины. Всегда перепроверяйте домены/IP в 2-3 разных источниках (urlscan.io + IPinfo + VT).
