# CyberChef: Сервес декодирования различных файлов, текста и тд.

CyberChef: Сервес декодирования различных файлов, текста и тд.

Экстракторы
 email, ip, url и тд
Различные кодировки  base64,65,85 и тд.

CAPA:
помогает узнать что исполняемый файл делает без реверс инженеринга
 К примеру для сетевого взаимодействия , манипулирования файлами , внедрения процессов и многого другого.

 REMnux
Виртуальная машина REMnux — это специализированный дистрибутив Linux . Она уже включает в себя такие инструменты, как Volatility, YARA, Wireshark, oledump и INetSim. Она также предоставляет среду, подобную песочнице , для анализа потенциально вредоносного программного обеспечения без риска для вашей основной системы. Это ваша готовая к работе лаборатория без необходимости ручной установки.

FlareVM  
FlareVM , или « Криминалистика, логический анализ и обратное проектирование », представляет собой всеобъемлющий и тщательно подобранный набор специализированных инструментов, разработанных специально для удовлетворения потребностей реверс-инженеров, аналитиков вредоносного ПО, специалистов по реагированию на инциденты, криминалистов и специалистов по тестированию на проникновение.

Обратное проектирование и отладка
Ghidra — разработанный Агентством национальной безопасности США (NSA) пакет программного обеспечения для обратного проектирования с открытым исходным кодом.
x64dbg — отладчик с открытым исходным кодом для бинарных файлов в форматах x64 и x32.
OllyDbg — отладчик для обратного проектирования на уровне ассемблера.
Radare2 — сложная платформа с открытым исходным кодом для обратного проектирования.
Binary Ninja — инструмент для дизассемблирования и декомпиляции бинарных файлов.
PEiD — инструмент для обнаружения упаковщиков, криптографов и компиляторов.
Дизассемблеры и декомпиляторы
CFF Explorer — редактор файлов PE , предназначенный для анализа и редактирования исполняемых файлов ( PE ).
Hopper Disassembler — отладчик, дизассемблер и декомпилятор.
RetDec — декомпилятор машинного кода с открытым исходным кодом.
Статический и динамический анализ
Process Hacker — сложный редактор памяти и наблюдатель за процессами.
PEview — портативная программа для просмотра исполняемых файлов ( PE ) с целью анализа.
Dependency Walker — инструмент для отображения зависимостей DLL-файлов исполняемого файла .
DIE (Detect It Easy) — инструмент для обнаружения упаковщиков, компиляторов и криптографов.
Судебная экспертиза и реагирование на инциденты
Volatility — платформа для анализа дампов оперативной памяти в целях криминалистической экспертизы памяти.
Rekall — платформа для анализа памяти в рамках реагирования на инциденты.
FTK Imager — инструменты для получения и анализа образов дисков в целях криминалистики.
Анализ сети
Wireshark — анализатор сетевых протоколов для записи и анализа трафика.
Nmap — инструмент для обнаружения уязвимостей и построения сетевых карт.
Netcat — полезный инструмент для чтения и записи данных по сетевым соединениям.
Анализ файлов
FileInsight — программа для просмотра и редактирования бинарных файлов.
Hex Fiend — лёгкий и быстрый шестнадцатеричный редактор.
HxD — программа для просмотра и редактирования бинарных файлов с помощью шестнадцатеричного редактора.
Скриптинг и автоматизация
Python — в основном ориентирован на автоматизацию с использованием модулей и инструментов Python.
PowerShell Empire — платформа дляпостэксплуатации уязвимостей в PowerShell .
Пакет программ Sysinternals
Autoruns — показывает, какие исполняемые файлы настроены для запуска во время загрузки системы.
Process Explorer — предоставляет информацию о запущенных процессах.
Монитор процессов — отслеживает и регистрирует активность процессов/потоков в режиме реального времени.
