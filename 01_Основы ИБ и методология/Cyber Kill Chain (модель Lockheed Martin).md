# Cyber Kill Chain (модель Lockheed Martin)

Cyber Kill Chain — структурированный подход к описанию этапов компьютерной атаки. Разработана для понимания тактик противника и построения эффективной обороны.

📌 1. РАЗВЕДКА (Reconnaissance)
Цель: сбор информации о цели до начала активных действий.
🔍 Техники и инструменты:

🛡️ Обнаружение и защита:
🔎 Анализ логов DNS / веб‑сервера на необычные запросы.
🔒 Ограничение публичной информации (отдел кадров, WhoIs Privacy).
⚠️ Мониторинг запросов к API поисковых систем с одного IP.

📦 2. ПОДГОТОВКА ВРЕДОНОСНОГО КОНТЕНТА (Weaponization)
Цель: создать средство доставки (эксплойт + полезная нагрузка).
⚙️ Типичные действия:
🔗 Подготовка фишингового письма с вредоносным вложением (PDF, Office, LNK).
💻 Сборка пейлоада (Metasploit, Cobalt Strike).
🔐 Шифрование / обфускация кода.
🎭 Маскировка под легитимное ПО (malvertising, supply chain).
🛡️ Защита:
❌ Запрет макросов, блокировка вложений по политикам.
🧠 Поведенческий анализ на endpoint (EDR).
🧪 Песочницы для неизвестных файлов.

📩 3. ДОСТАВКА (Delivery)
Цель: передать вредоносный объект жертве.
🚚 Каналы доставки:
✉️ Фишинг / spear-phishing.
🌐 Компрометация веб‑сайтов (watering hole).
🎛️ USB‑носители.
📲 Социальные сети, мессенджеры.
🔌 Атаки на цепочку поставок.
🛡️ Обнаружение:
📧 Фильтрация писем (DMARC, DKIM, SPF).
🕵️‍♂️ Анализ вложений в песочнице.
🚫 Блокировка подозрительных доменов / IP.

🧨 4. ЭКСПЛУАТАЦИЯ (Exploitation)
Цель: использовать уязвимость для выполнения кода.
🛠️ Методы:
🐚 Уязвимости браузеров / плагинов.
📄 Эксплуатация макросов или DDE в Office.
📦 Zero‑day / известные уязвимости (CVE).
💉 Эксплуатация ошибок конфигурации.
🛡️ Обнаружение:
📉 Обновления ПО, патчи.
🛡️ ASLR, DEP, EMET, AppLocker.
👀 Мониторинг аномальных процессов (PowerShell, WMI, rundll32).

🧬 5. УСТАНОВКА (Installation)
Цель: закрепиться в системе (persistence).
🔗 Типичные механизмы:
📁 Запись в автозагрузку (реестр, папки Startup).
⏰ Планировщик задач (schtasks, crontab).
🧩 DLL‑продажа, инжект в процессы.
🔌 Бэкдор в прошивке / загрузчике.
🛡️ Обнаружение:
🔐 Контроль целостности файлов (FIM в Wazuh, Osquery).
📊 Мониторинг реестра и запланированных задач.
📉 Отслеживание необычной активности после перезагрузки.

6. КОМАНДНО-УПРАВЛЯЮЩИЙ ЦЕНТР (C2, Command & Control)
Цель: установить канал связи с атакующим.
📡 Типы каналов:
🌐 HTTP/HTTPS (маскировка под легитимный трафик).
📡 DNS‑туннелирование.
🕸️ SMB, ICMP, скрытые протоколы.
🔄 Beacon‑ы (Cobalt Strike, Empire) с «засыпанием».
🛡️ Обнаружение:
🧐 Аномалии DNS (частые запросы к необычным доменам).
📈 Повторяющиеся интервалы трафика.
🔗 JA3/S‑хэши, анализ SSL/TLS‑рукопожатий.
🌍 Threat Intelligence (IOC, домены‑приманки).

7. ДЕЙСТВИЯ ПО ДОСТИЖЕНИЮ ЦЕЛИ (Actions on Objectives)
Цель: выполнить конечную задачу злоумышленника.
🎯 Примеры:
💸 Шифрование данных (ransomware).
🕵️‍♂️ Кража данных (data exfiltration).
🔑 Повышение привилегий, захват домена.
🌐 Lateral movement, распространение в сети.
🛡️ Обнаружение:
🚨 Дашборды SIEM с корреляцией событий.
📤 Мониторинг больших объёмов исходящего трафика.
🔒 DLP (Data Loss Prevention) — контроль передачи данных.
📋 Сегментация сети, привилегированный доступ (PAM).
