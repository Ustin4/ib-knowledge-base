# Расшифровка хешей

Онлайн-декодеры/базы данных:
CrackStation (https://crackstation.net/)
Бесплатная база хешей
Поддерживает md5, sha1, sha256, sha512
Оффлайн-версия доступна для скачивания

Hashes.com (https://hashes.com/en/decrypt/hash)
Большая база данных
Поддержка множества алгоритмов
Интеграция с John the Ripper

HashKiller (https://hashkiller.io/)
35+ миллиардов расшифрованных хешей
API доступно
Поддержка md5, sha1, sha256, NTLM

CMD5.org (https://www.cmd5.org/)
Китайский сервис
Огромная база (особенно md5)
Платные услуги для больших запросов

MD5Decrypt (https://md5decrypt.net/)
Бесплатный, с лимитами
Поддерживает 20+ алгоритмов

Сайты с радужными таблицами:
Project RainbowCrack (http://project-rainbowcrack.com/)
Таблицы для LM, NTLM, md5, sha1
Можно скачать или купить готовые таблицы
Инструменты для генерации

Freerainbowtables (https://www.freerainbowtables.com/)
Бесплатные таблицы
Форум сообщества
Инструкции по использованию

RainbowTables Online (http://rainbowtables.it64.com/)
Онлайн-поиск по таблицам
Ограниченный набор алгоритмов

Облачные сервисы взлома:
GPUHASH.me (https://gpuhash.me/)
Использует GPU для взлома
Поддержка множества алгоритмов
Платный сервис

OnlineHashCrack (https://www.onlinehashcrack.com/)
Бесплатные и премиум услуги
Взлом WPA, документов, хешей
Детальные отчеты

Специализированные сервисы:
NTLM Decrypter (https://ntlm.pw/)
Специализируется на NTLM хешах
Бесплатно для небольших запросов
WPA2 Hash Cracking (https://wpa-sec.stanev.org/)
Для WPA/WPA2 хешей
Статистика и база ESSID

CrackStation - Online Password Hash Cracking - MD5, SHA1, Linux, Rainbow Tables, etc.
