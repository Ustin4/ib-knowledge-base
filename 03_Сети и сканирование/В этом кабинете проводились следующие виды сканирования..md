# В этом кабинете проводились следующие виды сканирования.

В этом кабинете проводились следующие виды сканирования.
Тип сканирования портов
TCP SYN
Пример команды 
Sudo nmap-ss 
Пример команды
TCP Null Scan
sudo nmap -sN 10.64.176.241
TCP FIN Scan
sudo nmap -sF 10.64.176.241
TCP Рождественское сканирование
sudo nmap -sX 10.64.176.241
TCP Maimon Scan
sudo nmap -sM 10.64.176.241
Сканирование TCP ACK
sudo nmap -sA 10.64.176.241
Сканирование TCP-окна
sudo nmap -sW 10.64.176.241
Пользовательское сканирование TCP
sudo nmap --scanflags URGACKPSHRSTSYNFIN 10.64.176.241
Поддельный IP-адрес источника
sudo nmap -S SPOOFED_IP 10.64.176.241
Поддельный MAC-адрес
--spoof-mac SPOOFED_MAC
Сканирование ложной цели
nmap -D DECOY_IP,ME 10.64.176.241
Сканирование в режиме ожидания (зомби)
sudo nmap -sI ZOMBIE_IP 10.64.176.241
Разбить IP-данные на 8 байтов
-f
Разбить IP-данные на фрагменты по 16 байт.
-ff

Вариант
Цель
--source-port PORT_NUM
укажите номер исходного порта
--data-length NUM
добавить случайные данные для достижения заданной длины
Эти типы сканирования основаны на неожиданной установке флагов TCP для запроса ответа от портов. Сканирование Null, FIN и Xmas вызывает ответ от закрытых портов, в то время как сканирование Maimon, ACK и Window вызывает ответ от открытых и закрытых портов.
Вариант
Цель
--reason
объясняет, как Nmap пришел к своему выводу.
-v
многословный
-vv
очень многословный
-d
отладка
-dd
более подробная информация для отладки

Вариант
Значение

Пример скрытого но долго полного сканирования цели 

sudo nmap -sS -sU -p- -T4 -A -oA full_scan_report 192.168.1.100

· -sS: TCP SYN сканирование.
· -sU: UDP сканирование.
· -p-: Все 65535 TCP-портов (от 1 до 65535).
· -A: "Агрессивный" режим (ОС, версии, скрипты, трассировка).
· -oA: Вывод в три формата (normal, grepable, XML).
